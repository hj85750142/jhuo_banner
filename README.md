# jhuo_banner

Banner test website for Microsoft Monetize / Xandr placement **38213034**.

Website: https://hj85750142.github.io/jhuo_banner/

Uses the same legacy `ttj` integration as `jhuo-mic-shop` and `jhuo-macro`,
not AST:

```html
<script src="https://secure.adnxs.com/ttj?id=38213034"></script>
```

GitHub Pages publishes from the root of the `main` branch.
An actual banner depends on placement eligibility, available demand,
and browser privacy or ad-blocking settings. An empty ad response does not
mean the website is offline.
